Створіть просту систему інвентарю, яка дозволяє зберігати предмети різних типів.

1. Generic-клас
Створіть клас Inventory<T>, який:
- Зберігає елементи у List<T>.
- Має методи Add(T item) та Remove(T item).
- Має властивість Count.
- Дозволяє отримати предмет за індексом через індексатор.
- Реалізує IEnumerable<T> для підтримки foreach.

2. Generic-методи та ітератори
Додайте метод FindAll(Func<T, bool> predicate), який використовує yield return для повернення елементів, що відповідають умові.
Додайте Generic-метод ConvertAll<TResult>(Func<T, TResult> converter), який перетворює всі елементи інвентарю на інший тип і повертає List<TResult>.

3. Generic-інтерфейс та обмеження
Створіть інтерфейс IItem з властивістю Name.
Створіть клас ItemInventory<T>, який успадковує Inventory<T> з обмеженням where T : IItem.
Додайте метод пошуку предмета за назвою.

4. Використання колекцій
У Main() створіть декілька предметів та інвентар. Використайте:
- Додавання та видалення предметів.
- Перебір інвентарю через foreach.
- Фільтрацію через yield return.
- Перетворення предметів на колекцію їхніх назв.
- Пошук за назвою.
- Роботу з кожною стандартною колекцією.
