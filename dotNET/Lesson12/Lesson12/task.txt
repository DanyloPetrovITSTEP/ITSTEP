Створіть консольну програму File Manager, яка дозволяє користувачу керувати файлами та зберігати інформацію про них.

Програма повинна мати меню:
===== FILE MANAGER =====
1. Створити текстовий файл
2. Записати текст у файл
3. Прочитати текстовий файл
4. Скопіювати файл
5. Переглянути список файлів
6. Переглянути інформацію про файл
7. Зберегти дані користувача
8. Завантажити дані користувача
9. Видалити файл
0. Вихід

Не потрібно сильно звертати увагу на ідеальне рішення, достатньо базово реалізувати кожен пункт
